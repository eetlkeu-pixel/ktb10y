# 국고채 3·10년 요인 계산기

슬라이더로 세부 요인을 움직이면 국고채 3년·10년 적정금리, 10년−3년 스프레드, 채권가격 변화와 포지션별 손익이 즉시 계산된다. HTML 파일 하나(`index.html`)로 동작한다.

- 사이트: https://eetlkeu-pixel.github.io/ktb10y/
- 10년 ≈ π̄(기대인플레) + r̄*(실질 중립금리) + TP(텀프리미엄) + @(정책괴리·수급)
- 각 슬라이더는 그 요인이 10년 금리를 움직이는 폭(bp)이고, 합이 변화폭이다.
  - π̄: 전쟁·지정학, 확장재정, 원화 약세, 관세·공급망, 디스인플레
  - r̄*: 반도체 특수 종료·다운사이클, AI 투자, 고령화, 글로벌 중립금리, 가계부채
  - TP: 국고채 발행, 외국인 수요, 보험·연기금 수요, 미 국채 파급, 변동성
  - @: 고용·소비 둔화, 한은 기준금리 경로, 포지션 쏠림
- 슬라이더 값은 10년 영향(bp)이고, 3년 영향은 요인별 단기 민감도 `k3`를 곱해 계산한다.
- 전략 비교: 10년 롱, 3년 롱, 스티프너, 플래트너를 같은 DV01로 맞춰 가격 손익과 1년 캐리(기준금리 조달)를 비교한다.
- 채권가격은 반기 이표 채권으로 정확히 계산하고 듀레이션·볼록성 효과로 나눠 보여준다.
- 첫 화면: 국고채 3년·10년 최근 3개월 금리와 스프레드 차트. 선택한 내러티브의 적정금리를 차트 오른쪽 끝에 이어서 보여준다.
- 시나리오: 기본 내러티브 + 직접 저장(브라우저에 보관), 비교표, 초기화.

## 금리 자동 갱신

`.github/workflows/pages.yml`이 평일 18:10(KST)에 `scripts/update_yields.py`를 돌려 `index.html`의 `<script id="market">` 블록을 최근 약 130일치로 바꾸고 배포한다. 출처는 한국은행 ECOS(시장금리 일별)와 네이버 증권 중 최근 날짜가 더 늦은 쪽이다. 같으면 ECOS를 쓴다. ECOS 정식 키를 저장소 Secrets에 `ECOS_API_KEY`로 넣으면 sample 키 대신 쓴다(없어도 동작). Actions 탭에서 수동 실행도 된다.

## 내러티브 추가

틀(요인·3년 민감도·계산식)은 고정이다. 새 내러티브는 `<script id="data">`의 `presets`에 `name`, `story`, `f`(요인별 10년 bp) 한 줄을 추가하면 버튼·비교표·차트 출력만 바뀐다.

요인 목록·범위·기준값은 `index.html` 안의 `<script type="application/json" id="data">` 블록만 고치면 된다.

분석 도구이며 투자 권유가 아니다.

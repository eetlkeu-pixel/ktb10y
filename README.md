# 국고채 10년 내러티브 계산기

물가·성장 내러티브를 10년물 구성요소(π̄, r̄*, TP, @)의 변화로 옮기고, 반사성 승수와 포지션 오버슈팅을 반영해 상·하방 도달 범위를 추정한다.

- 10년 ≈ π̄ + r̄* + TP + @
- r̄* 변화 = β · Δg · min(H, 10) / 10
- 반사성 승수 m = 1 / (1 + β·φ − ψ)
- 적정 = 현재 + m·Δ, 극단 = 현재 + m·Δ·(1 + κ)

내러티브·지표·기준값은 `index.html` 안의 `<script type="application/json" id="data">` 블록에 있다. 이 블록만 고치면 된다.

분석 도구이며 투자 권유가 아니다.
